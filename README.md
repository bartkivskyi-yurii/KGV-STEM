STEM-проєкт: Обробка та аналіз зображень військової техніки
Цей репозиторій містить програмне рішення для обробки та аналізу зображень військової техніки на основі класичних методів комп’ютерної графіки.

Проєкт виконано в рамках дисципліни "Комп'ютерна графіка та візуалізація". Усі алгоритми (фільтрація, сегментація, колірні перетворення) реалізовано вручну за допомогою математичних операцій numpy, без використання вбудованих функцій алгоритмів з бібліотек на кшталт OpenCV.

Встановлення та налаштування
Склонуйте репозиторій на свій комп'ютер:

git clone <посилання_на_ваш_репозиторій>
cd 
Встановіть необхідні залежності. Для роботи потрібні лише numpy, Pillow (для вводу/виводу) та pytest (для автотестів):

pip install numpy pillow pytest
Переконайтеся, що в папці data/images/ є хоча б 10 тестових зображень у форматі .jpg або .png.

Інструкція із запуску
Програма запускається через командний рядок за допомогою файлу STEM_KGV.py. Параметри пайплайнів налаштовуються у файлі config.json, що дозволяє керувати методами без втручання в код.

Загальний синтаксис:

python STEM_KGV.py --pipeline <назва_пайплайну>
Доступні пайплайни команди:
Учасник 1:

student1_p1 — Виявлення замаскованої техніки: Градації сірого -> Фільтр Собеля -> Порогова сегментація.
python STEM_KGV.py --pipeline student1_p1
student1_p2 — Покращення знімків з БПЛА: Підвищення яскравості -> Градації сірого -> Еквалізація гістограми.
python STEM_KGV.py --pipeline student1_p2
Учасник 2:

student2_p1 — Виявлення цілей у тумані/димі: Градації сірого -> Еквалізація гістограми -> Порогова сегментація.
python STEM_KGV.py --pipeline student2_p1
student2_p2 — Аналіз аномалій поверхні: Градації сірого -> Фільтр Лапласа -> Порогова сегментація.
python STEM_KGV.py --pipeline student2_p2
Результати та Метрики
Після запуску будь-якого з пайплайнів у папці results/<назва_пайплайну> автоматично створяться оброблені зображення (наприклад, processed_image.png).

Також буде згенеровано файл metrics.json, який містить кількісний аналіз ефективності (MSE та PSNR) порівняно з оригінальним зображенням.

Запуск автотестів (Критерій C3)
Для перевірки коректності роботи окремих математичних методів реалізовано автоматичні тести за допомогою pytest. Щоб запустити їх, виконайте в корені проєкту:

pytest tests/
